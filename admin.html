Approvals storage (Supabase)

Submitted change requests are stored in a change_requests table in Supabase so Approvers can see them. One-time setup: open your Supabase project → SQL Editor, paste the SQL below and click Run. Then enter the project URL and the anon key (Project Settings → API), click Test, and Publish. 

-- OnePopHealth approvals: run once in Supabase → SQL Editor
create table if not exists public.change_requests (
  id           bigint generated always as identity primary key,
  type         text not null check (type in ('ecr', 'pac')),
  ticket       text,
  subject      text not null,
  form         jsonb not null,
  email_html   text not null,
  email_text   text not null,
  status       text not null default 'pending' check (status in ('pending', 'approved', 'rejected')),
  submitted_by text not null,
  submitted_at timestamptz not null default now(),
  decided_by   text,
  decided_at   timestamptz,
  comment      text
);
alter table public.change_requests enable row level security;

drop policy if exists "read requests" on public.change_requests;
create policy "read requests" on public.change_requests
  for select to anon using (true);

drop policy if exists "submit pending requests" on public.change_requests;
create policy "submit pending requests" on public.change_requests
  for insert to anon with check (status = 'pending' and decided_by is null);

drop policy if exists "decide pending requests" on public.change_requests;
create policy "decide pending requests" on public.change_requests
  for update to anon using (status = 'pending')
  with check (status in ('approved', 'rejected') and decided_by is not null);

grant select, insert, update on public.change_requests to anon;
grant usage on all sequences in schema public to anon;

VA

  1. In Excel, select the cells including the header row and copy (Ctrl+C).
  2. Click Paste from clipboard (recommended for big ranges), or click the box and press Ctrl+V.
  3. Big sheet? Copy it in batches (e.g. 5,000 rows at a time) — each paste adds rows; a repeated header row is skipped.
  4. Click Save to write data/va.json to the repository (uses the token from the Publish tab; max 100 MB).

Publish to GitHub

Your edits are saved as a draft in this browser only. Publishing commits data/layout.json and data/users.json to your repository so every visitor sees them. GitHub Pages usually updates within 1–5 minutes.

Drafts & backups

Prefer not to use a token? Download the JSON files and commit them to the data/ folder yourself.
