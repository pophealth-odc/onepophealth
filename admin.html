VA

  1. In Excel, select the cells including the header row and copy (Ctrl+C).
  2. Click Paste from clipboard (recommended for big ranges), or click the box and press Ctrl+V.
  3. Big sheet? Copy it in batches (e.g. 5,000 rows at a time) — each paste adds rows; a repeated header row is skipped.
  4. Click Save to write data/va.json to the repository (uses the token from the Publish tab; max 100 MB).

Publish to GitHub

Your edits are saved as a draft in this browser only. Publishing commits data/layout.json and data/users.json to your repository so every visitor sees them. GitHub Pages usually updates within 1–5 minutes.

Drafts & backups

Prefer not to use a token? Download the JSON files and commit them to the data/ folder yourself.
