VA

In Excel, select the cells including the header row, copy (Ctrl+C), click the box below and paste (Ctrl+V). For very large sheets, use Excel File → Save As → CSV UTF-8 and choose the file instead. Save writes it as data/va.json in the repository (uses the token from the Publish tab; max 100 MB).

Publish to GitHub

Your edits are saved as a draft in this browser only. Publishing commits data/layout.json and data/users.json to your repository so every visitor sees them. GitHub Pages usually updates within 1–5 minutes.

Drafts & backups

Prefer not to use a token? Download the JSON files and commit them to the data/ folder yourself.
